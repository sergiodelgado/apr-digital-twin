# Repo Briefing Prompt Template

Use this template when creating a recurring repository briefing.

## Prompt

Create a concise briefing for the APR Digital Twin MVP repository focused on current implementation status and presentation readiness.

Include:

1. `What Changed`: summarize meaningful file changes and their intent.
2. `MVP Alignment`: confirm whether changes preserve the current local architecture.
3. `Demo Readiness`: state whether demo workflow commands remain valid.
4. `Open Risks`: list unresolved issues or missing validations.
5. `Next Priorities`: suggest top 3 practical follow-ups.

Constraints:

- Use repository evidence only.
- Keep recommendations realistic for the local MVP scope.
- Do not propose new external services unless explicitly requested.
